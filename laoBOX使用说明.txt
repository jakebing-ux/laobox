laoBOX 本地包（OK影视 2.5 / FongMi 系 / 安卓 4.4 / NewBox）
========================================
= 组成 =（以龙门本地包为基础 + JSMTVBOX 修复版可用源增量）
 1) 龙门 jar 源 36 个（龙门影视/天天秒播/星芽短剧/豆瓣/哔哩哔哩/斗鱼直播等）
 2) 龙门采集源 41 个（量子/非凡/360/快看等资源站，在线接口）
 3) JSMTVBOX 增量：csp_ jar 源 103 个（APP影视/4K/短剧/影视/动漫/磁力/
    网盘/聚合搜索/体育/听书/儿童/教育/哔哩系列，走 spider.jar）
 4) 官源 6 个（腾讯/360/芒果/爱奇艺/搜狗/优酷）
    —— 【v3】学习 jsm.json 的 lib/ext 分离模式：
       api = lib/drpy2.min.js（drpy2 引擎 111KB）
       ext = lib/官源_*.js（修复版规则，腾讯/360 推荐段用 MVL 新接口）
       依赖 lib/drpy-core-lite.min.js（708KB 核心库，与引擎同目录）
       —— 适用支持 ES Module JS 源的播放器（NewBox 2.0.7 等，与 jsm.json 同构）
    —— 【v2 备用】单文件 ES5 版（lib/腾讯.js 等，框架+规则合并转译）
       供老 Rhino 播放器（OK影视 2.5 / 安卓 4.4）：把官源 site 的 api 改为
       ./lib/腾讯.js 并把 ext 改为 {}（或直接用 v2 配置地址）
 5) 直播 4 组（龙门 + migu/live/ipv6） + 解析接口 39 个

= 官源 v3 状态 =
 - 官源 | 腾讯：分类/搜索/首页推荐（MVL 新接口，Node 仿真 24 条）✓
 - 官源 | 360影视：分类/推荐 9 条/搜索 ✓

   首页推荐接口已被源站关闭（返回空，与播放器无关）

= 用法 =
 1. 把 laoBOX 文件夹整体复制到盒子任意目录（保持结构）：
      laoBOX/
      ├─ laoBOX.json
      ├─ jar/    （lm60601/dx0301/dx260509/spider 共4个jar）
      ├─ lib/    （drpy2.min.js + drpy-core-lite.min.js + 官源_*.js 规则
                  + 腾讯.js 等 v2 ES5 单文件备用）
      ├─ json/   （7 个爬虫配置）
      └─ tvboxtv.txt / live.txt（直播）
 2. 播放器 → 设置 → 配置地址/本地配置 → 选择 laoBOX.json
 3. 首页源可选手动选「官源 | 腾讯」
